# Change Request: CHG-014-fix-stage-bg-tag-matching

## 1. 요청 배경 및 목적
- 현장 배경(Stage Background) 탭에서 설정한 분위기 태그 매칭 로직의 동작 이상을 수정합니다.
- 곡(또는 찬양 슬라이드 그룹)에 설정된 분위기 태그와 일치하는 현장 배경 동영상들이 여러 개 있는 경우, 무작위로 하나의 배경이 선택되어 **한 곡 내 전체 슬라이드 동안 동일한 배경이 유지**되어야 합니다.
- 또한, 태그 일치 배경이 존재할 경우 **반드시 지정된 태그에 해당하는 배경들 중에서만 선택**되어야 하며, 불필요하게 fallback(기본/일반 또는 전체 배경)으로 넘어가거나 슬라이드마다 배경이 무작위로 계속 변경되는 현상을 해결합니다.

## 2. 핵심 요구사항
1. **태그 정규화 및 엄격한 태그 매칭**:
   - 태그 비교 시 공백(`trim()`), `#` 접두사 제거, 대소문자 무시를 포함한 태그 정규화를 적용합니다.
   - 곡의 태그와 일치하는 현장 배경 후보가 1개 이상 존재할 경우, 절대로 기본/일반이나 전체 배경 fallback으로 넘어가지 않고 오직 해당 태그 후보들 중에서만 선택합니다.
2. **곡 단위 배경 고정 (한 곡 전체 슬라이드 동일 배경 유지)**:
   - 한 곡(동일한 `praiseGroupId` 또는 `songTitle`)에 속한 슬라이드들에 대해 무작위 매칭된 배경이 고정 적용되어, 곡 내에서 슬라이드를 이동할 때 배경이 임의로 변경되지 않고 동일한 배경이 이어져 나오도록 보장합니다.
   - 슬라이드가 전환될 때(`SELECT_STAGE_BACKGROUND_BY_MOOD` 및 송출 로직) 곡 식별자를 참조하여 곡별 배경 고정을 유지합니다.
3. **프론트엔드 및 백엔드 매칭 엔진 동기화**:
   - `backend/services/mood_matching.py`, `backend/main.py`, `frontend/js/modules/editor-praise.js`, `frontend/js/presenter.js` 전반의 태그 매칭 및 곡 고정 배경 로직을 통일시킵니다.
