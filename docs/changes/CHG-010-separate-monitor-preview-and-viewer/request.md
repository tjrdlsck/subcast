# Change Request: CHG-010-separate-monitor-preview-and-viewer

## 1. 개요 (Overview)
에디터 내부의 '무대 모니터 미리보기 캔버스'와 실제 외부에 송출되는 '모니터링 뷰어 페이지'의 역할을 명확히 분리합니다.

## 2. 변경 요청 내역 (Request Details)
1. **무대 모니터 미리보기 (에디터 내 캔버스)**:
   - 레이아웃 위치/크기 조정, 도형/이미지 추가, 속성 변경 등의 작업 시 에디터 캔버스 상에서 즉시 실시간으로 시각적 미리보기가 반환 및 연동되어야 함.
2. **모니터링 페이지 (실제 송출 뷰어)**:
   - 외부 송출 화면(`viewer.html?mode=monitor` 등)에는 에디터 내에서 실시간 조작하는 내용이 전송되지 않고, 사용자가 **"레이아웃 저장"** 버튼을 눌렀을 때의 저장된 레이아웃 데이터만 최종 송출되어야 함.
