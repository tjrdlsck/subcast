# Change Request: CHG-025-praise-bg-dedup-algorithm

## 1. 개요 및 목적 (Overview & Objective)
- **요청 사항**: 에디터 페이지에서 찬양 곡 추가 및 찬양곡별 배경 선택 기능 실행 시, 슬라이드 목록에 동일한 배경 영상이 중복하여 설정되지 않도록 매칭 알고리즘을 개선합니다.
- **주요 목적**: 같은 분위기/태그(#경배/찬양, #잔잔/묵상 등)의 찬양곡이 여러 개 슬라이드 목록에 들어왔을 때 동일한 배경 영상이 반복 지정되는 현상을 방지하고, 이미 슬라이드 목록에서 사용 중인 배경 영상과의 중복을 피하여 다채로운 현장 연출 효과를 제공합니다.

## 2. 세부 요구사항 (Detailed Requirements)
1. **슬라이드 목록 기반 중복 방지 (Existing Slide Background Exclusion)**:
   - 새로운 찬양곡 슬라이드를 생성하거나 배경을 무작위/자동 할당할 때, 현재 프로젝트 슬라이드 목록(`projectData.slides`)에 이미 할당된 `overrideBgId`를 수집합니다.
2. **동일 태그 매칭 시 배경 영상 분산 (Tag Match Deduplication)**:
   - 동일 태그(예: `#경배/찬양`)를 가진 여러 곡이 연속 추가되거나 슬라이드 목록에 배치될 때, 이미 선택된 배경 영상 ID를 후보군에서 제외(Exclude)하여 서로 다른 배경 영상이 고르게 선택되도록 개선합니다.
3. **후보군 고갈 시 다단계 폴백 (Fallback Cascade Strategy)**:
   - 해당 태그의 모든 배경 영상이 이미 사용 중이어서 선택 가능한 남은 배경 영상이 없는 경우(후보군 고갈 시):
     - 1차 폴백: '기본/일반' 또는 범용 배경 중 미사용 배경 선택.
     - 2차 폴백: 전체 배경 중 미사용 배경 선택.
     - 3차 폴백: 모든 배경이 사용되었을 경우, 가장 이전에 사용했거나 최소 사용된 배경 영상을 우선 선택하여 직전 배경과의 연속 겹침 방지.
