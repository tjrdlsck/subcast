# Change Request: CHG-003-editor-properties-panel-ui

## 1. 개요
에디터의 속성 설정 패널의 폰트 크기 단위를 `vw`에서 `px`로 변경하고, 테두리 두께 및 그림자 블러 레이아웃을 깨끗하게 정돈하며, 속성 설정 패널을 접고 펼칠 수 있는 플로팅 동그라미 토글 버튼 기능을 추가합니다.

## 2. 요청 내역
1. **글씨 크기 단위 변경**: 캔버스 텍스트 크기 입력을 `vw` 대신 `px` 단위로 변경 및 표시.
2. **레이아웃 깨짐 개선**: 테두리 색상/두께, 그림자 색상/블러 입력 필드의 UI 찌그러짐 현상 해결 및 레이아웃 정돈.
3. **속성 설정 패널 접기/펼치기**: 패널 헤더 닫기(접기) 버튼 추가 및 접었을 때 동그라미 아이콘(🎨) 버튼으로 전환되어 다시 누르면 복원되는 기능 구현.
