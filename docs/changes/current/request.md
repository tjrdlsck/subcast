# Change Request: CHG-038 찬양 슬라이드 2분할 레이아웃 적용 및 성경/일반 슬라이드 1분할 단일 레이아웃 자동 분기

## 1. 요청 배경
- 모든 슬라이드에 무조건 2분할(현재/다음 자막) 레이아웃이 적용되면, 가사가 이어지는 찬양에는 적합하지만 성경 구절 및 설교/일반 슬라이드에서는 집중도를 저하시키는 문제 발생.

## 2. 요구사항 및 개선 목표
- **찬양 슬라이드 (Praise)**: 찬양 탭으로 추가된 슬라이드(`slide_praise_...` 또는 `category === 'praise'`)에 한하여 무대 모니터 **2분할(CURRENT + NEXT)** 레이아웃 유지.
- **성경 및 일반 슬라이드 (Bible / Normal)**: 1분할 단일 레이아웃(CURRENT 텍스트 영역 전용)으로 자동 조건부 분기하여 단일 슬라이드의 텍스트가 꽉 차고 깔끔하게 표시되도록 개선.

## 3. 사용자 승인 상태
- 사용자가 조건부 분기 적용 제안에 대해 **승인** 완료 (2026-08-06).
