# Change Request: CHG-036-push-and-reusable-change-docs

## 배경

변경마다 다섯 개의 상세 문서를 새 폴더에 만들면 현재 작업 기준과 과거 기록이 빠르게 누적된다. 완료된 작업은 Git 커밋으로 보존하고, 다음 작업부터는 이 다섯 파일을 재사용한다.

## 요청 사항

1. `request.md`, `impact-analysis.md`, `design.md`, `tasks.md`, `testing.md`를 `docs/changes/current/`에서 재사용한다.
2. 검증을 통과한 변경은 간결한 커밋 제목으로 현재 작업 브랜치에 커밋하고 푸쉬한다.
3. 테스트 실패, 보호 범위 위반, `main`·`master`, detached HEAD에서는 푸쉬하지 않는다.
4. 완료된 문서 전문은 Git 커밋 이력으로 보존한다.
5. 기존 변경 폴더는 이관 검증 후 삭제한다.

## 완료 기준

- 활성 작업 문서가 이 폴더의 다섯 파일로 고정된다.
- 커밋 제목은 변경 목적만 요약한다.
- 과거 내용은 Git 이력에서 복원 가능하다.
- 기존 `CHG-*` 폴더 삭제 후에도 현재 작업 문서와 요약 인덱스가 남는다.
