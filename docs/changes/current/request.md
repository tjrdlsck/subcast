# Change Request: CHG-037-fix-monitor-textbox-height-resizing

## 배경

사용자가 모니터 에디터(`editor-monitor.js`)에서 다음 슬라이드가 빈 슬라이드이거나 한 줄짜리 내용일 때, Fabric.js `fabric.Textbox` 객체의 자동 높이 줄어듦(Auto-height shrinking) 현상으로 인해 `nextBox`의 높이 비율(`heightPct`)이 부적절하게 축소되어 저장되는 문제가 발생함.
또한, 사용자가 가이드 박스의 세로 핸들(`scaleY`)을 끌어서 늘리려고 해도 Fabric.js Textbox의 자동 높이 계산 특성 때문에 높이가 늘어나지 않고 텍스트 한 줄 높이로 다시 원상복구되는 현상이 존재함.

## 요청 사항

1. **텍스트 박스 세로 크기 수동 변경 보장**:
   - 모니터 에디터 캔버스에서 텍스트 줄 수(1줄/빈 슬라이드 등)와 무관하게 사용자가 세로 리사이즈(Vertical Resize)를 수행하면 조정된 높이 비율(`heightPct`)이 정상 보존 및 반영되어야 함.
2. **자동 수축 방지 (Auto-Shrink Prevention)**:
   - 슬라이드 텍스트 변경이나 1줄 텍스트 입력 시 `heightPct`가 텍스트 콘텐츠 줄 수에 종속되어 강제로 쪼그라들지 않고 고정된 영역 높이를 유지하도록 개선.
3. **미리보기 및 방송 뷰어 동기화**:
   - 수정된 `heightPct` 및 박스 위치/크기가 모니터 뷰어(`viewer.html`, `monitor.html`) 및 DB 영속화 저장 시 그대로 유지되도록 설정.

## 완료 기준

- [ ] 1줄짜리 또는 빈 슬라이드 텍스트 상태에서도 가이드 박스 세로 리사이즈 조작 시 높이가 늘어나고 `heightPct`에 정상 반영된다.
- [ ] 텍스트 변경이나 탭 재진입 시 세로 높이가 자동으로 쪼그라들거나 원상복구되지 않고 설정된 영역 비율을 유지한다.
- [ ] 관련 렌더링 및 모니터 관련 단위/통합 테스트를 통과한다.
