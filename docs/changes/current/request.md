# Change Request: CHG-037 무대 모니터 가이드 박스 고정 더미 텍스트화 및 PiP 실시간 연동 UX 개선

## 1. 요청 배경
- 에디터 페이지의 무대 모니터 탭 편집 시, 선택된 슬라이드의 가변 텍스트를 직접 `fabric.Textbox`에 할당하여 가이드 텍스트 박스 크기가 슬라이드 글자 수에 직접 종속되는 현상 발생.
- 글자 수가 적으면 박스가 너무 작아 핸들 조작 및 레이아웃(영역 범위, 위치) 설정이 극도로 불편함.

## 2. 요구사항 및 개선 목표
- **표준 가이드 더미 텍스트(Standard Guide Dummy Text) 적용**: 메인 캔버스 텍스트박스에는 실제 슬라이드 글씨 대신 대표 가이드 문구(현재/다음 자막 영역 안내)를 배치하여 글자 수 영향 없이 8방향 핸들로 영역(Bounding Box) 크기 및 정렬을 자유롭게 조절.
- **측면 PiP 실시간 피드백 연동 (`pip-monitor-preview-box`)**: 메인 캔버스에서 가이드 박스를 수정할 때마다 측면의 PiP 미리보기 박스(`iframe` 모니터)로 broadcast가 전달되어 실제 선택된 슬라이드의 자막이 배치되는 모습을 실시간 동시 확인.
- **최소 영역 크기(Min Bounds) 지정**: 텍스트 박스가 너무 작아지는 현상을 방지하도록 최소 width/height 보장.

## 3. 사용자 승인 상태
- 사용자가 방안 2(PiP 연동 응용방안) 제시에 대해 **승인** 완료 (2026-08-06).
