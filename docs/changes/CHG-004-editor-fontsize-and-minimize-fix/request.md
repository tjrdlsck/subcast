# Change Request: CHG-004-editor-fontsize-and-minimize-fix

## 1. 개요
폰트 크기 변경 시 텍스트 박스 가로 폭(Width)이 고정되도록 개선하고, 속성 설정 패널 닫기(`✕`) 버튼 동작이 캔버스 개체 선택 시 덮어쓰이지 않도록 `.collapsed` 클래스로 처리합니다.

## 2. 요청 내역
1. **폰트 크기 변경 시 텍스트 박스 고정**: 폰트 크기 변경 시 `scaleX`/`scaleY`를 1로 보정하고 기존 픽셀 너비를 유지하여 텍스트박스 폭이 변하지 않게 고정.
2. **패널 닫기(`✕`) 버튼 동작 보장**: 패널 닫기 시 `.collapsed` 클래스 (`display: none !important`)를 적용하여 캔버스 객체 선택 시에도 접힌 상태가 유지되도록 보장.
