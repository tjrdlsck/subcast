# 업데이트 전 데이터 백업과 복원

자동 업데이트는 설치 파일을 시작하기 전에 사용자 데이터 전체를 ZIP으로 보관합니다. 위치는 `%APPDATA%\SubcastBackups\Subcast_날짜_시간_식별자.zip`입니다. 백업에 실패하면 설치를 시작하지 않습니다. 프로젝트, 찬양 및 모니터 DB, 설정, 태그, 배경 파일이 포함됩니다.

복원할 때는 다음 순서를 따릅니다.

1. Subcast를 트레이 메뉴에서도 완전히 종료합니다.
2. `%APPDATA%`에서 현재 `Subcast` 폴더를 다른 이름으로 바꿔 보관합니다. 이 폴더를 삭제하지 마세요.
3. 원하는 ZIP을 새 `Subcast` 폴더에 압축 해제합니다. ZIP 안의 `data`, `frontend`, `subcast_user.db` 등이 새 폴더 바로 아래에 있어야 합니다.
4. Subcast를 다시 실행해 프로젝트, 찬양, 배경, 모니터 설정을 확인합니다.

구버전의 자동 업데이트 기능으로 이 버전을 처음 설치하는 경우, 설치 후 프로그램이 자동으로 재실행되지 않을 수 있습니다. 원래 사용하던 Windows 계정에서 시작 메뉴나 바탕 화면의 Subcast를 직접 실행하세요. 이는 다른 관리자 계정의 데이터 폴더를 열지 않도록 하기 위한 조치입니다.
