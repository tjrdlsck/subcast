# Subcast 자막 송출 시스템

실시간 자막 및 슬라이드 송출을 위한 웹소켓 기반 분산 아키텍처 시스템입니다.

---

## ⚠️ BX-100 하드웨어 연동 시 필수 주의사항

하드웨어 비디오 스위처(Hardware Video Switcher)인 **보은전자 BX-100** 장비와 단색 크로마키(Chroma Key) 비디오 신호를 연동하여 자막을 합성할 경우, 방송 사고를 방지하기 위해 다음 설정 항목들을 반드시 확인해야 합니다.

### 1. 송출 뷰어 전체 화면 모드 (F11) 필수
* 브라우저 창(`viewer.html`)을 단순 창 형태로 띄울 경우 주소창, 탭 바, 스크롤바 및 OS 테두리가 비디오 신호에 섞여 카메라 영상 위에 그대로 노출되는 송출 사고가 발생합니다.
* 뷰어 화면을 믹서 장비 입력용 세컨드 디스플레이로 드래그한 뒤, 반드시 **F11 키**를 눌러 브라우저 전체 화면(Full Screen) 상태로 송출하십시오.

### 2. 하드웨어 해상도(Resolution) 매칭
* BX-100 장비가 수용할 수 있는 최대 출력 규격은 다음과 같습니다.
  - **지원 해상도**: $1080\text{p/i}$, $720\text{p}$, $480\text{p/i}$, $576\text{p/i}$
* 제어기(`presenter.html`)의 **해상도 설정 UI**에 장비의 해상도 규격(예: 가로 `1920` / 세로 `1080`)을 정확히 입력한 뒤 전송하십시오. 뷰어는 리사이즈 배율 공식(`setZoom`)을 통하여 기하 구조 깨짐 없이 최적의 비율로 동기화 렌더링됩니다.

### 3. 시스템 주사율(Refresh Rate) 수동 설정
* BX-100 장비는 아래의 특정 주파수 규격만 지원합니다.
  - **지원 주사율**: $60\text{Hz}$, $59.94\text{Hz}$, $50\text{Hz}$
* 윈도우 그래픽 제어판(NVIDIA/Intel 제어판) 또는 `고급 디스플레이 설정`에 진입하여, BX-100으로 출력 신호를 보내는 두 번째 디스플레이 포트의 새로 고침 빈도를 장비가 지원하는 새로고침 빈도로 명시적 고정해 주어야 합니다.
* *특히 인텔 내장 그래픽 드라이버 환경의 경우, 미세한 주파수 편차로 인해 신호가 차단되거나 인터레이스 규격 인식이 안 될 수 있으므로 정밀 매칭이 필요합니다.*

### 4. 송출용 OS 환경 통제
* **마우스 커서 숨김**: 마우스 포인터가 송출 화면에 남아 비디오 영상에 함께 캡처되지 않도록, 마우스를 메인 제어 모니터 영역으로 이동해 놓으십시오.
* **OS 알림 차단**: 윈도우 알림 배너나 타 메신저 알림창이 송출용 디스플레이에 노출되는 것을 예방하기 위해, 송출 PC의 윈도우 **집중 모드(Focus Assist)** 혹은 방해 금지 모드를 반드시 활성화하십시오.
