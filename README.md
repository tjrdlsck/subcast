# Subcast

Windows용 실시간 자막·슬라이드 송출 프로그램입니다. 제어 화면에서 내용을 편집하고 웹 브라우저 화면으로 자막과 슬라이드를 송출합니다.

## 실행

### 설치된 프로그램

Subcast를 실행하면 기본 설정에서 서버를 시작하고 제어 화면을 브라우저로 엽니다. 기본 포트는 `8000`이며 사용 중이면 다른 포트로 변경됩니다. 이 PC의 주소는 `http://127.0.0.1:<포트>/static/index.html` 형식입니다. 기본 서버 호스트는 `0.0.0.0`이며, 같은 네트워크의 다른 장치에서는 송출 PC의 IP 주소와 실제 포트를 사용합니다. 다른 장치에 주소를 공유할 때는 송출 PC의 방화벽과 네트워크 접근 범위를 확인하십시오.

사용자 데이터와 설정은 Windows `%APPDATA%\Subcast` 아래에 저장됩니다. 설정 파일은 `subcast_config.json`이며, 사용자 데이터베이스는 `subcast_user.db`입니다. 프로그램을 제거하거나 업데이트하기 전에 필요한 데이터를 별도로 백업하십시오.

### 소스에서 실행

Windows에서 Python 환경을 준비하고 프로젝트 루트에서 다음을 실행합니다.

소스 실행도 설치된 프로그램과 같은 `%APPDATA%\Subcast` 사용자 데이터를 사용합니다. 시험용으로 실행할 때는 기존 데이터를 먼저 백업하거나 별도의 Windows 사용자 환경을 사용하십시오.

```powershell
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe run.py
```

개발용 브라우저 테스트는 Node.js도 필요합니다. 준비 및 실행 방법은 [실제 브라우저 회귀 검증 안내](tests/browser/README.md)를 참고하십시오.

## 검증

Python 테스트는 프로젝트 루트에서 `venv\Scripts\python.exe -m pytest tests`로 실행합니다. 테스트는 임시 사용자 프로필과 앱 데이터 폴더를 사용하며, 성경 DB는 복사본으로 검사합니다. 실제 Edge 브라우저 시나리오와 테스트 데이터 격리, 결과물에 관한 설명은 [tests/browser/README.md](tests/browser/README.md)에 있습니다.

## 빌드

Windows에서 PyInstaller와 Inno Setup 6을 준비한 뒤 `venv\Scripts\python.exe build_all.py`를 실행합니다. 스크립트는 실행 파일, 무설치 ZIP, 설치 프로그램을 만들며 산출물은 `dist/`에 생성됩니다.

## ⚠️ OBS 및 BX-100 출력 연동 시 주의사항

Subcast는 OBS 투명 오버레이 출력을 사용합니다. OBS에서 자막과 영상 합성을 마친 뒤 하드웨어 비디오 스위처인 **보은전자 BX-100**으로 전달하는 경우, 방송 사고를 방지하기 위해 다음 설정 항목들을 확인하십시오.

### 1. 송출 뷰어 전체 화면 모드 (F11) 필수
* 브라우저 창(`viewer.html`)을 단순 창 형태로 띄울 경우 주소창, 탭 바, 스크롤바 및 OS 테두리가 비디오 신호에 섞여 카메라 영상 위에 그대로 노출되는 송출 사고가 발생합니다.
* 뷰어 화면을 믹서 장비 입력용 세컨드 디스플레이로 드래그한 뒤, 반드시 **F11 키**를 눌러 브라우저 전체 화면(Full Screen) 상태로 송출하십시오.

### 2. 하드웨어 해상도(Resolution) 매칭
* BX-100 장비가 수용할 수 있는 최대 출력 규격은 다음과 같습니다.
  - **지원 해상도**: $1080\text{p/i}$, $720\text{p}$, $480\text{p/i}$, $576\text{p/i}$
* 제어기(`presenter.html`)의 **해상도 설정 UI**에 장비의 해상도 규격(예: 가로 `1920` / 세로 `1080`)을 정확히 입력한 뒤 전송하십시오. 뷰어는 리사이즈 배율 공식(`setZoom`)을 통하여 기하 구조 깨짐 없이 최적의 비율로 동기화 렌더링됩니다.

### 3. 시스템 주사율(Refresh Rate) 수동 설정
* BX-100 장비는 아래의 특정 주파수 규격만 지원합니다.
  - **지원 주사율**: $60\text{Hz}$, $59.94\text{Hz}$, $50\text{Hz}$
* 윈도우 그래픽 제어판(NVIDIA/Intel 제어판) 또는 `고급 디스플레이 설정`에 진입하여, BX-100으로 출력 신호를 보내는 두 번째 디스플레이 포트의 새로 고침 빈도를 장비가 지원하는 새로고침 빈도로 명시적 고정해 주어야 합니다.
* *특히 인텔 내장 그래픽 드라이버 환경의 경우, 미세한 주파수 편차로 인해 신호가 차단되거나 인터레이스 규격 인식이 안 될 수 있으므로 정밀 매칭이 필요합니다.*

### 4. 송출용 OS 환경 통제
* **마우스 커서 숨김**: 마우스 포인터가 송출 화면에 남아 비디오 영상에 함께 캡처되지 않도록, 마우스를 메인 제어 모니터 영역으로 이동해 놓으십시오.
* **OS 알림 차단**: 윈도우 알림 배너나 타 메신저 알림창이 송출용 디스플레이에 노출되는 것을 예방하기 위해, 송출 PC의 윈도우 **집중 모드(Focus Assist)** 혹은 방해 금지 모드를 반드시 활성화하십시오.
